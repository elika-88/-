## 一、本次已完成

动效风格参考 claude.ai / chatgpt.com：时长短（120–320 ms）、减速曲线 `cubic-bezier(.2,0,0,1)`、位移小（≤ 8 px），正文内容不做弹跳。所有动画在 `prefers-reduced-motion: reduce` 下都会关闭。

| 区域 | 改动 |
| --- | --- |
| 动效系统 | 新增 `app/motion.css`，统一时长和曲线变量及 keyframes。补上了一直缺失的 `@keyframes fadeIn`：设置弹窗和弹出菜单原本引用了它，但它从未定义，所以这些动画以前都没有生效。 |
| 生成进度 | 新增 `GenerationProgress.tsx`：六阶段条（校验、分析、生成、核对、修正、完成），仅突出后端实际返回的当前阶段，不推断其他阶段已经完成；阶段为空时不补造阶段。显示实际已用时间，不显示百分比或估计完成时间。访客流式生成和登录用户后台任务共用这个组件。 |
| 加载态 | 首次生成、还没有结果时，用骨架屏代替“暂无学习材料”；运行中的状态文字带 Claude 风格的 shimmer 效果。 |
| 页签 | 滑动指示器：选中背景随 `--tab-index` 平滑移动。切换面板时内容淡入上移，摘要段落和要点依次错开出现。 |
| 测验 | 进度条改用 `role="progressbar"` 并带动画；选项依次入场、悬停时显示阴影且不改变点击位置；答对的图标弹出，答错的选项轻微抖动；解释区淡入；结果页改为环形进度加分数滚动计数。支持按数字键 1–9 或字母键 A–I 选择答案。 |
| 闪卡 | 按方向滑入或滑出（上一张、下一张）；支持 ← → 键切换，焦点会自动回到卡片；显示进度条和快捷键提示（触屏设备隐藏提示）；悬停时卡片抬起，翻转图标旋转。 |
| 上传 | 拖入文件时拖放区高亮、轻微放大，文字变为“Release to import”。 |
| 通用 | 按钮按下时缩放到 0.97；输入框聚焦时显示柔和的光环；原文对话框、重命名/删除对话框和移动端侧栏有打开动画（使用 `@starting-style`，不支持的浏览器直接显示，不影响使用）；原文高亮会渐显；切换引用时平滑滚动。 |

e2e 依赖的文本和角色没有改动，包括 `Generate materials`、`Generating`、`Question:` / `Answer:`、`Quiz progress`、`generation-stage` 等。

## 三、代码层面的问题与建议

1. **`globals.css` 约 2000 行，有多层覆盖。** 末尾用了大量 `html:root ...` 来提高优先级，压过前面的规则，还残留不少硬编码颜色（`#10a37f`、`#f6f6f6`、`#666`）。建议拆成 `tokens.css`、`layout.css`、`sidebar.css`、`settings.css`、`admin.css`，删掉被覆盖的旧规则，把颜色统一改为变量。
2. **i18n 不一致。** `GenerationJobStatus` 和 `StudySyncStatus` 用 `zh ? … : …` 三元表达式，工作区主界面和学习视图则写死英文，`translations.ts` 只覆盖了侧栏和设置。建议把所有文案统一收进 `translations.ts`，e2e 固定使用 `en`。
3. **字体没有加载。** 声明了 `Inter`，但没有引入，实际显示的是系统字体。可以用 `next/font` 自托管 Inter（中文可加 Noto Sans SC 子集），或者干脆把字体栈改为系统字体。
4. **`StudyWorkspace.tsx` 过重。** 生成、导入、编辑对话框的逻辑都挤在一个组件里，建议拆成 `useGuestGeneration`、`useCourseImport` 和 `<CourseImport />`、`<EditLectureDialog />`。
5. **无障碍。**
   - 拖放区缺少对键盘用户的说明。
   - 对话框的 `aria-labelledby` 已经有了，但 `SourceEvidence` 的标题永远是 “Lecture source”，可以加上引用编号。
6. **性能。**
   - `HistorySidebar` 每次渲染都会对全部课程的全文执行 `toLocaleLowerCase()`，课程多时会卡。建议用 `useDeferredValue` 延迟处理搜索词，并缓存标题索引。
   - 讲稿很长时，`SourceEvidence` 会一次渲染全文，可以只渲染引用附近的段落，按需展开其余部分。

## 四、新功能建议（按投入产出比排序）

1. **间隔重复复习（SM-2 或 FSRS）。** 闪卡翻面后提供“忘了 / 模糊 / 记得”三个按钮，按掌握程度安排下次复习，首页显示“今日待复习 N 张”。这最能提高留存。
2. **导出。** 支持导出为 Anki（`.apkg` 或 CSV）、Markdown 或打印版 PDF 讲义，以及把测验导出为可打印的试卷。
3. **基于讲稿的问答。** 用户可以针对讲稿提问，回答必须附带引用，能复用现有的 evidence 校验管线。
4. **知识结构图。** 用 `topics` 和 `keyPoints` 生成思维导图，点击节点可跳到对应的要点或原文。
5. **错题本与学习统计。** 跨课程汇总答错的题，并提供正确率曲线和连续学习天数。
6. **测验模式扩展。** 增加限时模式、打乱选项顺序，以及“只练错题”。
7. **分享链接。** 生成只读的学习材料链接，方便同学之间分享。
8. **PWA 与离线。** 已生成的材料支持离线复习，适合移动端通勤场景。
9. **生成延迟。** 目前一次要 3 分钟左右，可以把摘要先流式展示给用户，测验和闪卡随后补齐，这样感知等待时间会明显缩短。

## 五、侧边栏重新设计（第二轮）

原来的问题：

- **两层内容交替：** 收起时，展开层向左平移并淡出，窄栏层从 92% 缩放淡入。两层同时出现在画面里，图标位置还会跳一下，看起来很突兀。
- **配色不统一：** 侧栏底色 `#f9f9f9` 和边框 `#e8e8e8` 都是写死的，和主题变量不一致，深色模式下尤其生硬。
- **规则重复：** `.lecture-sidebar` 和 `.workspace` 在 `globals.css` 里被定义了三次，宽度（268/260px）和过渡时长（200/280ms）都不一样。

新方案（`app/sidebar.css` 和 `HistorySidebar.tsx`）：

- **同步动画：** 侧栏宽度和主区域左边距用同一条曲线 `cubic-bezier(.32,.72,0,1)`、同一个时长（320ms）一起过渡，整页平滑移动。
- **图标原地不动：** 窄栏图标和展开状态下的图标在同一水平位置，收起时只有文字消失。离开的一层 110ms 快速淡出，进入的一层延迟约 100ms 再淡入。不再有缩放或平移。
- **窄栏 logo：** 鼠标悬停时变成“展开”图标（和 ChatGPT 一样）；点窄栏里的搜索图标会展开侧栏并自动聚焦搜索框。
- **历史记录分组：** 按“今天 / 过去 7 天 / 更早”分组，组标题滚动时固定在顶部，列表底部有渐隐遮罩；标题过长时在右侧渐隐，而不是直接截断成省略号。
- **操作菜单：** “…”菜单有弹出动画，点击外部或按 Esc 会关闭；键盘聚焦到某一项时也会显示“…”按钮。
- **记住状态：** 收起或展开的状态会保存在 localStorage，刷新后保持；按 Ctrl/⌘+B 可以切换（小屏幕上是打开或关闭抽屉）。
- **移动端抽屉：** 从左侧滑入，背景加模糊遮罩，打开和关闭都有动画。
- **配色：** 全部改用主题变量，浅色和深色一致。

## 六、其他设计建议

1. **首页层次：** 现在一进来就是一整块表单。可以参考 Claude 首页，只在中间放一个大输入框（粘贴讲稿或拖入文件），把“标题”“YouTube 链接”“输出语言”这些次要选项收进输入框下方的一排小按钮，第一屏会清爽很多。
2. **排版：**
   - 加载真正的 Inter 字体，中文用 `Noto Sans SC` 或系统中文字体。
   - 正文 15–16px、行高 1.7 左右。
   - 标题用 `letter-spacing: -0.01em`。
   - 学习材料正文限制最大宽度约 68ch，更适合阅读。
3. **品牌色：** 现在绿色只出现在零星几处。建议定一个主色、一个中性灰阶，把按钮、选中态、焦点环、进度统一起来。主按钮可以用品牌色，不要用纯黑。
4. **学习材料页：** 页签可以改成顶部吸附的 segmented control，滚动时也能随时切换；“查看来源”可以改成右侧抽屉，这样读原文时不会挡住内容。
5. **空状态插画：** “暂无学习材料”可以加一个轻量插画和三步引导（粘贴 → 生成 → 复习），降低第一次使用的门槛。
6. **设置弹窗：** 目前是整页遮罩，可以改成更轻的面板。主题切换时整体颜色可以用约 200ms 的过渡，现在是瞬间跳变。
