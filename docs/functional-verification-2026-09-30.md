# 全站功能验收（2026-09-30）

分支：`codex/exam-prep-upgrade`。本轮以 `2d33a34` 为起点，在独立工作区完成；已读取远程分支，未发现尚未包含的 `origin/main` 提交。没有修改主工作区队友的未提交文件。

## 修复

- 管理员状态接口原先始终返回未登录，导致刷新后台必须重新登录。现在依据服务端会话检查状态，未登录仍返回普通状态响应，且不返回密钥或配置内容。
- 保存配置后直接应用服务端确认的配置和版本号，避免后续单独读取失败把成功保存误报为失败；同时更新真实审计记录。
- 临时读取失败不再先清空当前后台配置；退出时立即清空客户端管理员视图。
- 获取模型、保存和退出操作互斥，避免较晚返回的操作覆盖更新的状态。
- 空的 API 地址、模型和协议环境变量使用默认值；保留环境密钥时使用同一默认地址判断，修改目标地址仍要求输入新密钥。
- 登录限流集成测试包含二十余次真实 scrypt 验证，独立设置 20 秒时限，保留全部限流断言。
