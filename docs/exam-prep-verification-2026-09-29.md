# 备考专区验证记录（2026-09-29）

验证分支：`codex/exam-prep-upgrade`，基于 `b608052`。本记录随该分支交付，验证结果不代表 Vercel 生产环境已更新。

## 本轮发现与修复

- SAT 缺少独立语境时必须拒绝；此前可绕过 25–150 词校验。
- SAT / TOEFL 不同短文允许使用同一标准提问句。重复检测改为同时比较题干和语境；IELTS 仍按共用原文检查重复题干。真实 SAT 调用曾因旧检测规则被误拒绝，修正后复测成功。
- TOEFL 补词提示明确要求完整目标词仅出现一次，服务端遮罩后再交给模型审核；删除与此矛盾的提示。
- 审题模型使用与考生实际看到的一致的材料：IELTS 全文，SAT / TOEFL 每题语境。
