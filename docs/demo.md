# 现场演示

1. 提前启动生产版本：`npm run build`，`npm start`。确认模型 ID 与服务可用列表一致。
2. 点击 Load demo lecture，展示字数；也可粘贴另一篇讲稿。
3. 点击 Generate materials，展示真实分析、生成和审核状态。本次实测需约三分钟，期间讲解产品问题与流程。
4. 展示摘要和独立要点，打开 View source，说明引文直接来自讲稿。
5. 打开 Quiz，选择答案并 Check answer，展示解释与来源；完成后可复习错题主题。
6. 打开 Flashcards，翻转卡片并切换下一张。
7. 修改讲稿重新生成；旧材料会明确标记，不可冒充新生成。

SERVER_CONFIG 时检查模型名称、凭据和地址；限流时检查额度；超时时保留输入，减少讲稿长度后重试。不要用固定结果替代现场运行。

演示源文件 `public/demo/research-methods.txt` 为本项目编写的教学示例，约1,538词，不冒充大学课程录音。它是输入素材，不是生成结果。

完整演示时长包含生成等待和操作展示。AI审核不能代替人的判断。
