## 已知限制

- 学习历史仍存当前浏览器，账号课程记录 API 尚未接入前端自动同步。同一浏览器切换账号仍使用该浏览器的本机历史。
- 生成允许访客使用，目前没有用户级额度和并发控制。大规模公开使用前需要补充成本控制。
- 本次真实 AI 成功不代表稳定成功率或人工评估的准确率。97 秒包含自动修复，长讲稿仍可能更慢或失败；系统引用检查不等同于人工审核。
- 未做生产注册写入、压力测试、邮件找回密码、完整安全渗透测试，或 15 MB 上限文件的线上验收。生产依赖扫描不覆盖所有应用逻辑风险。
- 扫描 PDF 仍需 OCR，旧 `.ppt` 需要另存为 `.pptx`；YouTube 是否能提取取决于字幕与第三方服务可用性。
