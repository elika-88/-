# 账号学习记录云同步：交付与验收

日期：2026-09-23。任务范围：1.0 第一项任务——将工作区接入已有账号学习记录 API。

## 已实现

- 登录用户从数据库加载课程；新建、编辑、生成结果、重命名、删除自动同步。访客记录仍保存在本机。
- 650 ms 防抖、串行保存、服务端 revision 检测、保存中/成功/失败状态。
- 账号切换立即卸载旧工作区，取消旧生成、提取与同步请求；旧异步响应不能覆盖新身份。跨标签页 BroadcastChannel 加 storage-event 降级通知。
- 请求携带预期账号，服务端比对真实 Cookie 用户，防止旧标签页在 Cookie 切换后写错账号。
- 保存失败、响应丢失、保存途中继续编辑、删除冲突都有恢复机制。刷新后先验证账号，再比较云端版本与暂存编辑。
- 冲突不静默覆盖：保留本地副本为新课程，或用户确认后采用云端版本；云端删除不被旧编辑自动恢复。
- 访客课程仅在点击导入后上传，保留原件；确定性导入 ID 防重复，支持部分失败后重试。
- 设置导出当前工作区及未保存编辑，不再始终导出访客历史。
- 测试使用独立 SQLite 数据库与 `.next-e2e` 构建目录，不读取生产 Turso 连接；保留 3000 端口开发服务。

## 使用方式

1. 登录账号，在工作区创建或编辑课程，等待顶部“Saved to cloud / 已保存到云端”。
2. 在另一浏览器登录同一账号，课程与生成材料会加载；已打开页面可点“Refresh cloud / 刷新云端”。可见页面每 30 秒检查，回到页面和恢复网络时也检查。
3. 若发现访客课程，点击“Import guest lectures / 导入访客课程”才会上传，原件留在本机。
4. 失败点击“Retry sync / 重试同步”；冲突选择“Keep local copy / 保留本地副本”或确认采用云端状态。

## 边界

- 不是实时共同编辑；答题进度持久化和后台生成任务属于后续任务。
- 未保存编辑暂存在当前标签页按账号隔离的 sessionStorage。刷新可恢复；关闭标签页前应保存成功或下载 JSON，不能把暂存当成永久离线备份。浏览器禁止存储/容量不足时有警告。
- 生产跨设备同步依赖已配置的持久化 Turso；没有修改、导出或上传 API 密钥。
- 沿用当前每账号 1,000 条记录及每次保存 2 MiB 限制；大量长课件的列表分页与容量扩展仍是后续优化项。
- 本任务没有发布此前遗留的四个生成/字幕文件修改。
